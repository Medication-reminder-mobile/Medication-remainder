# Data Flow Design

## Level 0 DFD

User → Medication App → Database → Notification System

## Level 1 DFD

1. User inputs medication details
2. System processes input
3. Data is stored in database
4. Reminder is scheduled
5. Notification is sent to user

## Explanation

The system receives input from the user, processes it through the application logic, stores it in the database, and triggers notifications based on scheduled reminders.
